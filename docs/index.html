Give an agent a secret without pasting it into the chat.

A local tool asks for a key by name. keydrop prints a one-shot link on your tailnet. You open it on a device signed in to your tailnet, paste the value, and it goes straight into the login keychain. The page shuts itself down, and the tool reads the value back by name.

Install → Source on GitHub

One command on your side. One field on theirs. The page has no script, no cookies, no stylesheet fetched from anywhere, and the input asks browsers and password managers not to save what you type.

How it works

One path for the value, checked on every request.

1
Ask

Your tool runs keydrop request <name>. keydrop opens a tailscale serve route and prints a link once.

2
Open

You open it on a device signed in to your tailnet. The route, the Host, your tailnet login and the token are checked, in that order.

3
Store

The value goes to security -i on stdin as hex, is read back, and the digests are compared.

4
Gone

The page says Stored, the route is closed and confirmed closed. Your tool reads the value back with keydrop get.

The full flow, with the diagram and every check →
Fig 01 · Lifetime

One link. One submit. Then nothing.

The link stops working after one good submit, after the TTL (15 minutes by default, an hour at most), after five bad requests, or on keydrop cancel. Every one of those paths closes the route.

/3vQx…pending
/3vQx…stored
/8kLm…ttl 15m
/pR2w…5 bad requests
/zN7c…cancelled
Fig 02 · Who can open it

Only you.

Every request needs your Tailscale-User-Login, which tailscale serve sets from the connection and peers can't forge. So a chat message is a fine place for the link: to anyone the tailnet won't authenticate as you, it's useless.

What it defends against, and what it doesn't →
  • route is still keydrop's own
  • Host is on the allowlist
  • Tailscale-User-Login is the owner
  • token matches, in constant time
  • anything else: a bare 404
Fig 03 · Stored

Stored means read back and matched.

keydrop hands the value to security -i on stdin as hex, reads it back, and compares digests. Only a match counts. Logs hold the name, the time and the outcome, never the value.

browser → keydrop
hex on stdin → security -i
read back
digest == digest → Stored
Fig 04 · Read-back

Nothing renders a value.

keydrop list prints names only. The vault and home pages are write-only. The value is read back by name, by the tool that asked, with keydrop get, which prints no trailing newline when stdout isn't a terminal, so command substitution is clean.

Install

Read the file. Then install it.

One Python file, no dependencies. The install is a fetch, a diff you read, and an install of the commit you read, never the working tree. Needs macOS, Tailscale with serve and HTTPS certificates, and python3.
