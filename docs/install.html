Install

Read it, then install it.

One Python file, no dependencies. The install is a fetch, a diff you read, and an install of the commit you read, never the working tree.

Requirements Install or upgrade Configure Commands
01 · Requirements

Three things, nothing else.

  • A vault. keydrop is platform agnostic: the spec defines a small vault adapter interface. The reference adapter is the macOS login keychain, driven through /usr/bin/security. Other systems need an adapter for their own store.
  • Tailscale, with tailscale serve available to your user and HTTPS certificates enabled for the tailnet. Without certificates every page refuses to start unless you pass --http, and the home page doesn't run at all.
  • python3, 3.9 or later. No other dependencies.
02 · Install, or upgrade

The diff line is the review.

The last line installs the commit you read, never the working tree. Run the same block to upgrade.

03 · Configuration

One key has no default.

Read from ~/.config/keydrop/config.json, or the file named by KEYDROP_CONFIG. Environment variables override the file.

{
  "owner_login": "you@example.com"
}

owner_login is your Tailscale login exactly as tailscale status shows it. keydrop never falls back to accepting any login. keydrop config prints the settings in effect.

04 · Commands

Nine commands.

keydrop request <name> [--note "…"] [--ttl 15m]
Prints a one-shot link and returns. The page runs in the background.
keydrop get <name>
Prints the stored value, for local tools. No trailing newline when stdout isn't a terminal.
keydrop list
Names only. Never values.
keydrop status
Pending requests and vault sessions.
keydrop cancel <name>
Ends a pending request. cancel vault ends a vault session.
keydrop vault [--ttl 15m]
A session link for listing, adding, replacing and deleting entries.
keydrop home
The always-on vault page, for launchd. HTTPS only.
keydrop home --new-link | --stop | --unlock
Mint a new link, take the page down and keep it down, or clear a stop or lockout.
keydrop config
The settings in effect. Never a value.

Names are lowercase letters, digits, ., _ and -, up to 64 characters. A key named openai-api-key is stored as a generic password with service keydrop.openai-api-key and account keydrop.
